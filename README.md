# Projeto-Java-Hotel
# INTRODUÇÃO  
O projeto foi desenvolvido como atividade acadêmica para as disciplinas de Linguagem de Programação II e Laboratório de Programação II, tendo como finalidade aplicar, de maneira prática, os conhecimentos relacionados à programação e aos princípios da Programação Orientada a Objetos (POO) utilizando a linguagem Java.

O projeto foi desenvolvido em quarteto e consiste no desenvolvimento de um Sistema de Gerenciamento de Reservas de Hotel, elaborado para representar, de forma simplificada, algumas das principais operações envolvidas no gerenciamento de hóspedes, quartos e reservas.

# DESCRIÇÃO DO PROJETO

O Sistema de Gerenciamento de Reservas de Hotel foi desenvolvido com o propósito de simular as operações básicas relacionadas ao controle de hospedagens.

Por meio do sistema, o usuário pode cadastrar hóspedes, consultar os quartos disponíveis, realizar reservas e visualizar as informações registradas. As informações são organizadas através de diferentes classes, cada uma responsável por representar uma determinada entidade ou funcionalidade do sistema.

# Estrutura do Projeto
### Hospede — Armazena os dados dos hóspedes.
### Quarto — Representa os quartos e suas informações.
### Reserva — Gerencia os dados das reservas.
### Hotel — Responsável pelo gerenciamento dos hóspedes, quartos e reservas.
### MainHotel — Classe principal responsável pela execução do sistema e pelo menu interativo.
